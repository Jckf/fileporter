    What's the difference?

    Private sends everything through an encrypted relay, so neither of you learns the other's IP address. The relay only passes on encrypted data it can't read, but like any server it sees your IP address. Transfers are slower.

    Fast connects the two browsers directly when the network allows it, which is much faster but shows each side the other's IP address. It's only used if both of you choose Fast; otherwise the transfer stays private.
